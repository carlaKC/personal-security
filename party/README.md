# Running a Security Party

This guide is for the person running a security party. It covers what the party is for, how to run it, and which documents to share with your guests.

You don't need to be a security expert, but you should be comfortable with phones and accounts, and able to help someone who gets stuck.

## What Success Looks Like

The party is a success if everyone:
- Understands what to look out for now, which they didn't need to before.
- Has taken a few concrete steps: at minimum, setting up a password manager with two-factor login and adding a couple of passwords to it.

It's a bonus if people feel confident enough to run one with their own friends, or to help their parents get set up.

## Shape of the Party

1. Opening talk (~15 min): explain what's changed, what matters and what we're doing today.
2. Checklist (~90 min): everyone works through the party checklist, while you (and any other technical friends) help.
3. Wrap up (~10 min): fill in follow-ups, share the take-home page and mention the parents guide.

These timings are guesses, and will be updated after the first run.

Ground rule: help each other, but nobody types anyone else's passwords.
